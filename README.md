# Energy-Efficiency-Analysis-of-IEEE-802.15.4-Network-Using-AODVEEP-
Analyzed the energy efficiency of IEEE 802.15.4 networks using the modified AODV Energy-Efficient Protocol (AODVEEP) through NS-2 simulations. Evaluated node count, traffic flow, packet rate, and coverage area, comparing energy consumption, throughput, delay, and packet loss against standard AODV for IoT applications.
